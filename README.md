# CrashBayesian — supplementary analysis code

The analysis package is in [Supplementary_Code](Supplementary_Code/README.md). Start with its README for reproduction commands, dependencies and limitations.

It contains aggregate inputs, model sources, seeds and settings for 17 fit specifications, simulation and temporal-validation scripts, saved results, and a SHA-256 file manifest. It is distinct from the earlier Bogotá network-base example. Full posterior chains, individual crash records and geographic snapshots are not included. Preparation-time audit notes retain their original date and status. Attribution and licensing are provided inside the package.
