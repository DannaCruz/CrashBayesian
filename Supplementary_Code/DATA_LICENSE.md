# Data licensing and attribution

## Crash records

Source: Secretaría Distrital de Movilidad, Datos Abiertos Bogotá, *Histórico
Siniestros Bogotá D.C.*

Portal: <https://datosabiertos.bogota.gov.co/organization/sdm?groups=transporte&tags=Accidente>

License: Creative Commons Attribution 4.0 (CC BY 4.0).

The compressed file in `raw/` preserves the source observations used by this
project. Files in `processed/` are derived versions created through
deduplication, projection, spatial clipping, support assignment and graph
construction.
